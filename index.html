GUIDE

설치 및 첫 시작 안내

macOS 간편 설치 (보안/손상 경고 없이 바로 실행)

  1. 추천 — 터미널 1줄 자동 설치: 터미널(Terminal) 앱에 아래 명령어를 붙여넣으면 Apple Silicon/Intel에 맞춰 설치·실행까지 한 번에 끝납니다.
curl -fsSL https://lillizz.github.io/merry-christmas-tree-web/install-mac.sh | bash -s -- friends
  1. 직접 .dmg 설치 시: MerryChristmasTree를 응용 프로그램 폴더로 복사한 뒤 "손상되었기 때문에 열 수 없음" 안내가 뜨면 아래 명령어를 한 번 실행하세요.
xattr -cr /Applications/MerryChristmasTree.app

Windows SmartScreen 안내 시 실행 방법

  1. 다운로드한 Setup.exe 파일을 실행합니다.
  2. "Windows의 PC 보호" 창이 나타나면 좌측의 추가 정보를 클릭합니다.
  3. 아래에 나타나는 실행 버튼을 누르면 설치가 바로 진행됩니다.

친구 · 가족 방 3단계 시작하기

  1. 앱 실행 후 새 방 만들기를 눌러 초대코드를 발급하거나, 친구에게 받은 초대코드를 입력하세요.
  2. 방에서 사용할 닉네임과 로그인용 숫자 4자리 PIN을 설정해 입장합니다.
  3. 바탕화면 트리를 클릭하면 타임캡슐을 작성하고 어드벤트 · 산타 선물을 바로 즐길 수 있습니다.
